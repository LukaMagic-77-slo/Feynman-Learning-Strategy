# 高等数学知识目录（初稿）

`catalog.json` 与现有概率论 `knowledge.json` 分开保存。`modules` 按课程学习顺序排列；目前只为第一部分“函数与极限”撰写了知识条目，后续部分只有目录。

条目由本项目独立撰写，尚待用户提供参考书后逐条核对。当前仅供网页浏览，**没有**写入 `feynman_knowledge` 或向量索引，也没有接入问答与费曼练习。不要将浏览条目的状态理解为已经验证的检索效果。

每条记录使用稳定 ID、所属子模块、组别、主题、正文和关键词。核对参考书时应记录书名、版本及可复查的章节或页码；核对后再确定是否修改原文以及何时入库。进入向量检索前，必须用实际嵌入模型的分词器检查每条检索文本的长度，并完成高等数学独立测试集评估。
