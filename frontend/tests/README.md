# 前端交互测试

flows.spec.js 使用 Playwright 检查问答、赞踩改票、章节主题练习、解释评价、主题切换和手机布局，并检查知识库范围提示。

先按 [前端说明](../README.md) 安装依赖、准备浏览器，并启动 8000 端口后端。然后在 frontend/ 执行：

```bash
npm run test:ui
```

模型请求与反馈写入被模拟，不额外消费模型额度；会话、健康检查和 Dashboard 使用运行中的后端，需有效数据库。测试不代表真实模型质量验证。

截图和报告写入 test-results/ 等临时目录，不提交 GitHub。调整页面时保留语义标签与可访问按钮名称，避免通过删除断言让测试表面通过。
